🎯 予算管理

カテゴリごとに月の予算を決めておくと、レポートで使いすぎがひと目で分かり、使いすぎそうなときは通知でお知らせします。

このページの内容
  • 予算を設定する
  • 予算の履歴を確認・編集する
  • 予算アラート

予算を設定する

  1. ⚙️ 設定 →「予算管理」を開きます。画面上部で当月の予算合計と設定済みカテゴリ数を確認できます。
  2. 複数カテゴリなら まとめて予算を設定（設定済みの場合は「予算をまとめて更新」）、 1件だけなら右上の ＋ をタップします。
  3. カテゴリ・金額・適用開始月を選んで 保存 します。
  4. 設定した予算は、レポートの月次詳細で「使った額/予算」のバーとして表示されます。 予算を超えると赤色になります。
予算は「適用開始月」から先の月にずっと適用されます。 金額を変えたいときは、新しい開始月で追加すれば履歴として管理されます。

予算の履歴を確認・編集する

「予算の履歴」のカテゴリ行をタップすると、そのカテゴリの過去〜未来の全履歴が 適用開始月の新しい順で表示されます。

  • ✓
    当月に適用されている行には「現在適用中」バッジが付きます。
  • ✓
    行をタップすると編集シートが開きます。
  • ✓
    行を左にスワイプすると削除できます。

予算アラート

⚙️ 設定 →「通知」の「予算アラートの通知」をONにしておくと、 予算の8割を超えたカテゴリがあったとき、その瞬間にプッシュ通知でお知らせします。

同じ月・同じカテゴリのアラートは1回だけ届きます。 通知が多いと感じる場合は、「予算アラートの通知」をOFFにすると停止できます。
予算超過・残額少なめのお知らせは支出一覧の画面上には表示されず、 プッシュ通知とお知らせ一覧（ホームのベルアイコン）でのみお届けします。
