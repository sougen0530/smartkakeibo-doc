📊 レポートを見る

月次・年次のグラフで支出を振り返ります。予算との比較や、月ごとのメモ書きもここで行えます。

このページの内容
  • 月次レポート
  • 年次レポート（プレミアム）
  • 集計の基準を切り替える
  • レポートにコメントを残す
  • 外部AIへ共有する

月次レポート

「レポート」タブを開くと、まず月次レポートが表示されます （画面上部のセグメントで月次／年次を切り替えられます）。

  • ✓
    選んだ月のカテゴリ構成比（円グラフ）とカテゴリ内訳が確認できます。
  • ✓
    予算対比が「使った額/予算」のバーで表示され、超過すると赤色になります。
  • ✓
    カテゴリ内訳の行をタップすると、その明細を日付ごとにまとめて表示します。 日付・金額の並び順はワンタップで切り替えられます。

年次レポート（プレミアム）

年次レポートでは、1年間の収支バランスと月別の積み上げ棒グラフに加えて、 カテゴリごとに月ごとの支出と予算を比較できます。カテゴリをタップすると、月別の支出・予算・消化状況が開きます。

棒グラフの月をタップすると、その月の内訳（円グラフ）と予算との比較を表示する月次詳細が開きます。

年次レポートはプレミアム限定です。

集計の基準を切り替える

「日付基準/確定基準」で、すべてのデータで見るか、締め確認済みのデータだけで見るかを選べます。 上部の ◀ ▶ で年・月を切り替えられます。

初期表示（集計基準／表示対象／カテゴリ表示）は ⚙️ 設定 → 「レポート設定」であらかじめ決めておけます。

レポートにコメントを残す

月次レポート・年次レポートの末尾には、表示中の年月（年次は年）に紐づくコメント入力欄があります。 「今月は旅行があったので食費が多め」といったメモを残しておくと、あとから見返したときに理由が分かります。 入力内容は自動保存されます。

外部AIへ共有する

レポート画面の「外部AIへ共有」は、プレミアム未加入でも全ユーザーが利用できます。

  1. ⚙️ 設定 →「AI設定」の「共有コンテキスト」に、共有用のテンプレートを登録しておきます。
  2. レポート画面で「外部AIへ共有」を選び、使いたいコンテキストを選択します。
  3. JSON形式の支払データ・予算データが共有されます。コンテキストごとに、 グラフ画像を一緒に送るかどうかも切り替えられます。

アプリの中で完結するAIチャットについてはAIチャットをご覧ください。
