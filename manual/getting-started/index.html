スマート家計簿でできること

スマート家計簿は、パートナーとの生活費の割り勘・精算を手軽にすることを軸にした家計簿アプリです。 もちろんおひとりでの利用（共有OFF）にも対応していて、その場合は割り勘まわりの表示がすべて消え、 シンプルな家計簿として動作します。

  • ✓
    毎日の記録：支出・入金の記録、レシート撮影からの自動入力、決済アプリの画面からの取り込み
  • ✓
    割り勘と精算：支払ごとの負担割合、立替、月次の締め作業による精算金額の確定
  • ✓
    自動化：固定費の自動起票、支払名からのカテゴリ自動分類、クレジットカードCSVの取り込み
  • ✓
    振り返り：月次・年次レポート、カテゴリ別の予算対比、予算アラート通知

初回起動：データを引き継ぐ／新しくはじめる

アプリを本当に初めて起動したとき（未設定かつ端末にデータがないとき）、最初に 「データ引き継ぎ」の画面が表示されます。

  1. 他の端末から引き継ぐを選ぶと、同じ Apple ID の iCloud に保存されている全データ （設定・支払データ・レシート画像・カテゴリ）を取得して復元します。復元が終わると初期設定ウィザードは すべてスキップされ、そのまま前の端末の続きから使えます。
  2. 新しくはじめるを選ぶと、続けて初期設定ウィザードが開きます。 引き継ぎを試してクラウドにデータが無かった場合も、こちらへ進みます。
機種変更のときは：先に旧端末で 「アカウント設定 → iCloudとデータを同期する」がONになっていることを確認してください。 OFFのまま機種変更すると、データは旧端末の中だけに残ります。

初期設定ウィザード

「新しくはじめる」を選ぶと、次の順番でセットアップを案内します。 各ステップはスキップでき、あとから設定画面でいつでも変更できます。

ステップ内容
1. ユーザー名表示名を入力します。パートナーへの招待メッセージにも使われます
2. 使い方の選択「ひとりで使う」／「パートナーを招待する」／「パートナーから招待されている」の3択。 招待する場合は続けて招待リンクの作成と締め設定を、招待されている場合はリンクの貼り付け・QRコード読み取りでの参加を案内します
3. カテゴリテンプレート3種類のテンプレート（フラット／固定費・変動費／必須生活費・ゆとり費）から選んでカテゴリを一括生成します
4. 共有するカテゴリを選ぶパートナー共有を選んだときだけ表示されます。どのカテゴリを共有するかをまとめてトグル選択します
5. カテゴリの詳細修正生成されたカテゴリの名前・アイコンなどを調整します
6. 通知の許可締め作業や予算アラートのプッシュ通知を受け取るかを選びます
7. プレミアムのご案内プレミアム機能の紹介です。ここで登録しなくても、あとから設定メニューで登録できます
招待リンクやQRコードから参加に成功した場合は、カテゴリテンプレート以降のステップが自動でスキップされます。 オーナー側のカテゴリ・予算・共有設定がそのまま取り込まれるため、自分で作り直す必要はありません。

ホーム（支出一覧）画面の見かた

ホーム画面の上部にはヘッダーカードがあり、◀ ▶ で表示する年月を切り替えられます。 カードをタップすると開閉でき、開いているときは金額サマリーと今月の未精算額（共有ON時）が表示されます。 合計カードの近くには前月比（「先月より ¥3,200 増」など）も表示されます。

アカウント設定とアプリロック

Apple ID（iCloud）でのログイン

ログインは任意です。未ログインでも家計簿機能はそのまま使えます。 ログアウトしても家計簿データは端末に残ります（顔認証ロックは無効になります）。

顔認証ロック

ログイン中かつ端末が生体認証に対応している場合、「Face ID でロック」を有効にできます。 ONにすると、アプリの起動時と前面に戻ったときにロック画面が全面に表示され、認証するまで中身が見えません。

iCloud同期（自分の端末どうし）

「iCloudとデータを同期する」をONにすると、同じ Apple ID の自分の端末どうしで、 家計簿の全データ（設定・支払データ・レシート画像・カテゴリ）が同期されます。 画面ではiCloudアカウントの状態・最終同期の時刻・前回の同期エラーを確認できます。

これは「自分の端末どうしの同期」です。パートナーとの共有はまったく別の仕組みで、 「パートナー共有設定」から行います。詳しくはパートナーと共有するをご覧ください。

外観（テーマカラー）

「外観」から8色のテーマカラーを選べます。ダークモードはiPhone本体の設定に追従します。
