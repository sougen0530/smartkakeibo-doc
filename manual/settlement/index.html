✅ 月の締め作業と精算

月に一度、その月の共通支払を確認して精算金額を確定する作業です。締めると明細が凍結され、確定レポートとして保存されます。

このページの内容
  • 締め作業タブが表示される条件
  • 締め作業の手順
  • 締めると何が起こるか
  • 二重締めの防止
  • 締めを取り消す
  • 精算データの自動記帳
  • 締めサマリーを共有する

締め作業タブが表示される条件

締め作業タブは、⚙️ 設定 →「パートナー共有設定」で 「パートナーと家計簿を共有する」と「共有データの締め作業をする」の両方がONのときだけ表示されます。 どちらかがOFFになった瞬間、締め作業タブは非表示になります（表示中だった場合は支出一覧タブへ自動的に戻ります）。

締め作業の手順

  1. 「締め作業」タブを開きます。対象の月が自動で選ばれています（前回締めた月の翌月）。
  2. 一覧の支出をひとつずつ確認し、左の ○ をタップしてチェックを付けます。 内容を直したいときは右の ✏️ をタップします。
  3. 全部まとめてチェックしたいときは「一括選択」が使えます。
  4. 途中でやめるときは「下書き保存（中断）」をタップすれば、チェック状態が保存されます。
  5. 確認が終わったら「◯年◯月の締め作業を完了する」をタップします。
  6. 確認ダイアログで「完了する」を選ぶと、精算金額が確定してレポートに保存されます。
確定チェックの変更やカテゴリの変更などの操作は、その都度自動保存されます。 途中でアプリを閉じても作業内容は失われません。
締め作業を実行できるのはオーナーだけです。 参加者も支払データのチェックによる確定・確定解除はできますが、締めの実行はできません。 参加者の画面にはその案内が表示されるので、確認が終わったらオーナーに締めを依頼してください。

締めると何が起こるか

  • ✓
    その月の支出データがロック（凍結）され、🔒マークが付いて編集・削除できなくなります。
  • ✓
    その月の最終的な精算金額とカテゴリ別の支出が「確定レポート」として保存されます。
  • ✓
    締め作業完了直後に、精算サマリー画面が自動で開きます。
未確定のデータが残ったまま完了しようとすると警告が表示されます。 そのまま締めた場合、未確定データは精算対象に含まれず、翌月以降の締め作業画面に 「過去の未確定データ」として引き続き表示されます。

二重締めの防止

パートナーが自分の端末で先に締めを完了した月は、あなたの端末でも自動的に「締め済み」と表示されます （「この月はパートナー側で締め済みです」）。この月は再度締めることも、取り消すこともできません。 精算額はパートナーの端末で確認してください。

締め作業は必ずどちらか一方の端末で行うようにしましょう。

締めを取り消す

間違えて締め完了にしてしまった場合は、締め作業画面で該当月を表示し、 「この月の締めを取り消す」から解除できます。

  • ✓
    明細のロックが解除され、再編集・再締めができるようになります。
  • ✓
    自動で起票された精算明細と、確定レポートは削除されます。
パートナー側で締められた月は取り消せません（前項参照）。

精算データの自動記帳

「締め作業確定時に精算データを作成する」をONにしている場合、精算金額が 「自動精算」という支払として自動で記帳されます。受け取る側のときはマイナス金額で記録されます。

支払名（初期値: 共通支出の精算）やカテゴリは「パートナー共有設定」で変更できます。

締めサマリーを共有する

締め作業を完了すると、その月の精算サマリー画面が自動で開きます。 「画像で保存」ボタンで、パートナーに送れるカード画像を生成できます。

サマリーを閉じると、自動的に支出一覧タブへ戻ります。
